# 設置手順書 — LINE公式アカウントを作るところから

Kurage LINE CRM は、**LINE公式アカウントに届いた相談を、送ってきた人ごとに記録して返す窓口**です。
LINEを触ったことがない方でも、この順番どおりに進めれば動きます。所要 40〜60分。

---

## 0. 用意するもの

| | |
|---|---|
| ご自身のLINEアカウント | スマホで普段使っているもの。これが管理画面へのログイン鍵になります |
| PHPが動くレンタルサーバー | ロリポップ／ヘテムル／さくら／エックスサーバー など。**PHP 7.0以上・pdo_sqlite・cURL・HTTPS** |
| メールアドレス | LINEビジネスIDの登録に使います |

データベースサーバー（MySQL）は要りません。ファイル1つ（SQLite）に保存します。

### IDが3つ出てきて混乱しやすいので、先に整理します

```
①あなたの個人LINE          … ログインの鍵。相手には見えません
     ↓ これでログインして作る
②LINEビジネスID             … 会社・事業者としての管理者アカウント
     ↓ この下にぶら下がる
③LINE公式アカウント (@から始まるID) … お客様が友だち追加する窓口。相談が届くのはここ
```

お客様から見えるのは **③だけ** です。①はあくまで鍵です。

---

## 1. LINE公式アカウントを作る（無料）

1. https://www.linebiz.com/jp/entry/ を開く
2. 「**LINEアカウントで登録**」を選び、ご自身のLINEでログイン（スマホに確認が出ます）
3. 会社名・業種・地域などを入れて作成

これで **③LINE公式アカウント** ができ、`@` から始まるIDが割り当てられます（例: `@271hokhu`）。
このIDは**お客様に友だち追加してもらうためのもの**なので、控えておいてください。

> **IDの文字列を自分で決めたい場合**は「プレミアムID」（月100円／年1,200円・税別）が要ります。
> 自動で割り当てられたIDのままでも機能はまったく同じです。

### 料金プランについて

| プラン | 月額 | 送信できる数 |
|---|---|---|
| コミュニケーション | 0円 | 200通 |
| ライト | 5,000円 | 5,000通 |
| スタンダード | 15,000円 | 30,000通 |

**ここでいう「通数」は、こちらから送る（プッシュする）分だけ**です。
届いた相談への返信は**通数に数えられません**（後述）。まずは0円のままで始められます。

## 2. Messaging API を有効にする

届いた相談をご自身のサーバーで受け取るための設定です。

1. https://manager.line.biz/ を開く（①の個人LINEでログイン）
2. 作った公式アカウントを選ぶ
3. 右上の **設定** → 左メニューの **Messaging API**
4. 「**Messaging APIを利用する**」を押す
5. 「開発者情報」を聞かれたら、名前とメールアドレスを入れる
6. 「プロバイダー」を新しく作る。**ここに入れた名前は後から変えられません。**
   お客様に見える場面があるので、**会社名や屋号**を入れてください
7. プライバシーポリシー・利用規約のURLは**空のままでも進めます**（後から設定できます）
8. 内容を確認して「OK」

### 鍵を2つ控える

有効化すると **LINE Developers**（開発者向けの管理画面）が使えるようになります。

1. https://developers.line.biz/console/ を開く
2. 作られたプロバイダー → チャネルを選ぶ
3. **「チャネル基本設定」タブ** → 下のほうの **チャネルシークレット**（32文字）をコピー
4. **「Messaging API設定」タブ** → 一番下の **チャネルアクセストークン（長期）** の
   「発行」を押してコピー（とても長い文字列です）

> この2つは**パスワードと同じ**です。人に見せない、メールに書かない、
> 画面共有中に開かないでください。万一漏れたら、同じ画面から**再発行**すれば古いものは無効になります。

---

## 3. サーバーに置く

1. ZIPを展開し、**`public/` の中身**をサーバーの公開フォルダへアップロードします。
   置き場所はどこでも構いません（例: `あなたのドメイン/crm/`）
2. `klcrm_data/` フォルダの**書き込み権限を 777** にします
   （FTPソフトで右クリック → 属性／パーミッションの変更）
3. ブラウザで `https://あなたのドメイン/crm/check.php` を開く

チェック画面が出て、**すべて ○ になれば、そのサーバーで動きます。**

<details>
<summary>× が出たとき</summary>

- **PHPのバージョンが古い** … 同じフォルダの `.htaccess` にサーバー会社の指定を書きます。
  ヘテムル／ロリポップなら `AddHandler php-script .php` の1行で PHP8系になります。
  サーバー会社ごとに書式が違うので、契約中のサーバーのマニュアルで「PHPバージョン 切り替え」を確認してください。
- **klcrm_data に書き込めません** … 手順2の権限変更（777）が反映されていません。
- **HTTPSではありません** … LINEは `https://` でないとWebhookを登録できません。
  無料SSLはたいていのレンタルサーバーに付いています。
</details>

チェックが終わったら、**`check.php` は削除してください**（設定の状態が見えるため）。

---

## 4. 設定ファイルを作る

`klcrm_config.php.example` をコピーして **`klcrm_config.php`** という名前にし、開いて埋めます。

```php
define('KLCRM_TITLE',              '○○商店 お客様窓口');  // 画面に出る名前
define('KLCRM_PASSWORD',           'ここに管理画面のパスワード');
define('KLCRM_LINE_CHANNEL_SECRET','手順2でコピーしたチャネルシークレット');
define('KLCRM_LINE_ACCESS_TOKEN',  '手順2でコピーしたアクセストークン');
define('KLCRM_LINE_BASIC_ID',      '@271hokhu');  // ご自身の公式アカウントのID
define('KLCRM_AUTO_REPLY',  'メッセージありがとうございます。担当者が確認して、あらためてご連絡します。');
define('KLCRM_FOLLOW_REPLY','友だち追加ありがとうございます。ご相談をこのトークにお送りください。');
define('KLCRM_PUSH_LIMIT',  200);   // ご契約プランの月間通数
```

アップロードしたら、`https://あなたのドメイン/crm/klcrm_config.php` をブラウザで開いて、
**403（閲覧できません）になること**を必ず確かめてください。中身が表示される場合は
`.htaccess` が効いていないので、サーバー会社に確認してください。

---

## 5. Webhook（受け口）を登録する

1. https://developers.line.biz/console/ → チャネル → **Messaging API設定**タブ
2. **Webhook URL** に `https://あなたのドメイン/crm/webhook.php` を入れて「更新」
3. 「**検証**」を押す → **成功** と出ればつながっています
4. **「Webhookの利用」を必ずオンにする**（ここを忘れると、何も届きません）
5. 同じ画面の下のほうにある **「応答メッセージ」を オフ**、**「あいさつメッセージ」を オフ** にします
   （LINE側の自動返信とこのシステムの自動返信が二重になるのを防ぎます）

### 動作の確認

スマホでご自身の公式アカウントを友だち追加し、何かメッセージを送ってください。
`https://あなたのドメイン/crm/` を開くと、そのメッセージが載っているはずです。

## 6. 使う

| 場所 | できること |
|---|---|
| **左** | 相談者の一覧。**未対応が上・赤い●**。「対応済みにする」を押すと下がります |
| **中** | その人とのトーク履歴。**この人のメッセージだけを検索**、1件ずつ／全文をコピー |
| **右** | **ノート**（1人1枚。打ち合わせ記録を書き足していく）と、連絡先（会社名・本名・電話・メール・URL） |

**新しいメッセージが届くと、対応済みにした相手も自動で未対応に戻ります。**
「返したつもりで放置していた」が起きない作りです。

### 返信は2通りあります

- **いつものLINEの画面から返す**（LINE公式アカウントアプリ、または https://manager.line.biz/ のチャット）
  → **通数は消費しません。** お客様も担当者もふだんどおりです。
  ただし、**LINEの画面から送った返信はこのシステムには記録されません**（LINEに取得手段が無いためです）。
- **この画面の返信欄から送る**
  → **記録が残ります**が、**プッシュ通数を1通消費します**。
  画面の上に今月の残り通数が出ます。

> 使い分けの目安: ふだんはLINEで返し、**記録を残したいやり取りだけ**この画面から送る。
> あるいは、返した内容をノートに1行書いておく。

## よくあるつまずき

| 症状 | 原因 |
|---|---|
| メッセージが届かない | 「Webhookの利用」がオフ。手順5-4 |
| 検証で失敗する | URLの綴り違い、または `https` になっていない |
| 「このアカウントでは個別の問い合わせを受け付けておりません」と自動で返る | LINE側の「応答メッセージ」がオン。手順5-5 |
| 500エラー | `klcrm_data` の書き込み権限（777）か、PHPのバージョン。`check.php` で分かります |
| 画面が真っ白 | PHPが5.6で動いている。`.htaccess` の記述。`check.php` で分かります |

---

## 押さえておくと安心なこと

- **userId** は、そのアカウント限定の識別子です。ブロック→再追加しても同じなので、顧客の鍵として使えます。
- **氏名・メール・電話はLINEからは取れません。** 画面に出る名前はLINEのニックネームで、
  本名とは限りません。だから本名欄を別に用意しています。
- お客様がブロックすると、プロフィール（名前・アイコン）は取得できなくなります。
  取れたときだけ更新するので、過去の記録は消えません。
